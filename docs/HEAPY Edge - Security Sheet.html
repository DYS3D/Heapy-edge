ForClient IT and facilities

Draft for HEAPY review before it goes to any client. Remote updates are designed but not built yet (Phase 3).

HEAPY Edge is a small data collector that HEAPY places on your building automation (BAS) network. It reads trend data from your BAS controllers and sends it to HEAPY for energy and fault analysis. It only reads. It never changes a setpoint, schedule or any other value.

At a glance

What IT needs to know

HardwareA HEAPY-supplied box (Raspberry Pi 5 class or industrial mini-PC, DIN-rail mount), or software on a Linux VM you provide.
Network portsOne port on the BAS network. Optionally a second port on a network with internet access, so the BAS network stays cut off from the internet.
InternetOutbound HTTPS (TCP 443) to one HEAPY address only. No inbound connections, no port forwarding, no VPN required. Works through your web proxy.
BAS trafficBACnet/IP on UDP 47808 on the BAS network (and, where used, Modbus TCP 502, Niagara/Haystack HTTPS, SNMP UDP 161). Discovery uses standard BACnet Who-Is.
AddressesA static IP or DHCP reservation on the BAS network, and a BACnet device number that is not in use (HEAPY suggests one; you confirm).
Data sentPoint names, descriptions, units and values with timestamps (for example "AHU-1 supply air temperature, 55.2 °F"). No personal data, no user accounts, no video or badge data.
Safety

How it protects your BAS

Read-onlyThe software has no write function. It sends only read requests (ReadProperty, ReadPropertyMultiple, Who-Is, and optional change-of-value subscriptions).
Gentle on controllersAt most 5 requests per second to any one controller (adjustable), one request at a time per controller, and one at a time per routed trunk such as an MS/TP network. Readings are batched so a 15-minute trend of a whole AHU is usually a single request.
ScansDevice discovery can be limited to hours you choose (for example 22:00 to 06:00) and to device number ranges.
RoutingDoes not change BACnet routing, BBMD tables or any controller setting.
FailuresA controller that stops answering is retried every 5 minutes, not repeatedly. If the internet link is down, data is kept on the box (30 days or more) and sent later.
Security

How the box is secured

EncryptionAll data to HEAPY is sent over TLS (HTTPS).
IdentityEach box is paired once with a one-time code and gets its own key. HEAPY can revoke a box's key at any time. The key is stored on the box readable only by the collector.
Setup pageA local web page on the BAS network side (port 8770), protected by a password set at installation, with limits on failed sign-ins.
UpdatesSoftware updates come from HEAPY over the same outbound connection and are checked before they are installed; a failed update rolls back by itself.
RemovalUnplug the box. Nothing is installed on your controllers or servers.
Checklist

What HEAPY asks you for

  1. A network drop (or VM) on the BAS network, and a static IP or reservation.
  2. Permission for outbound HTTPS to the HEAPY address (given at install), or the proxy address to use.
  3. A free BACnet device number for the box.
  4. Any hours when discovery scans should not run.
  5. A contact for the BAS network (usually the controls contractor or facilities).
